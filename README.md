# ИИ-Офис

Живой 3D-офис для всех ИИ-агентов на Маке: здание на острове, по этажу на проект, агенты за столами со статусами. Если агент ждёт разрешения, его можно одобрить прямо в офисе.

## Как устроено

```
Claude Code / Codex ──hook──▶ hub/office_hook.py ──HTTP──▶ hub/server.py (127.0.0.1:4747) ──SSE──▶ web/index.html
                                                                ▲                                   (в ИИ-Офис.app или браузере)
                                                                └──── POST /api/decide (кнопка «Одобрить»)
```

- `hub/server.py` — хаб, только стандартная библиотека Python 3.9 (системный `/usr/bin/python3` на Маке). Хранит состояние сессий, раздаёт интерфейс, шлёт обновления через SSE и сохраняет состояние в `data/state.json`.
- `hub/office_hook.py` — хук для Claude Code и Codex. Пересылает событие в хаб. При любой ошибке выходит молча (код 0, без вывода), поэтому агент работает как обычно. Решение о разрешении печатает, только если оно принято в офисе.
- `web/index.html` — интерфейс (three.js из `web/vendor`, при недоступности берётся с CDN). Если хаба нет (например, страница открыта как артефакт), включается демо-режим с выдуманными данными.
- `app/` — нативное окно `ИИ-Офис.app` (AppKit + WKWebView), собирается скриптом `app/build.sh`.

### Как статусы берутся из хуков
Этаж — имя git-корня из `cwd`.
- `UserPromptSubmit` → работает, задача = текст промпта.
- `PreToolUse` → работает, задача = описание инструмента.
- `PermissionRequest` → ждёт тебя.
- `Stop` → готово.
- `StopFailure` → застрял.
- `SessionEnd` → агент уходит из офиса.
- Если 15 минут нет событий → отдыхает; через 12 часов агент забывается.

### Разрешения
Vibe Island остаётся основным. Хук `PermissionRequest` ждёт решения из офиса, только пока офис открыт (есть SSE-зритель), и не дольше `approveWait` секунд (по умолчанию 60, меняется в окне «Подключить ИИ»). Если решения нет, хук выходит без вывода, и решать продолжают терминал или Vibe Island. Как Claude Code совмещает решения нескольких хуков PermissionRequest одновременно, пока не проверено вживую.

### Защита
Хаб слушает только `127.0.0.1`. POST-запросы проходят только с заголовком `X-Office: 1` и `Host` равным 127.0.0.1 или localhost, поэтому чужая страница в браузере не может одобрить действие.

## Что умеет

- **Агенты офиса и чат.** Кнопка «Нанять» запускает Claude (`claude -p`, только хук офиса), Codex (`codex exec --json`) или Antigravity (`agy -p`) в папке проекта. Их поток превращается в чат: ответы, команды и правки. Разговор продолжается через `--resume`. Сессии в терминале видны в чате как история: промпты и финальные ответы присылает хук. Сессию Claude на Маке можно продолжить в офисе (`--fork-session`).
- **Лимиты.** 5 часов, неделя и месяц для Claude, Codex, Gemini и Cursor/Grok Bot. Берутся из локальной базы Vibe Island (только чтение), для Codex запасной источник — его собственные логи. Агент, у которого лимит почти кончился, выглядит уставшим, а без лимита засыпает за столом.
- **Пристройка Grok.** Боты Grok Bot сидят в отдельном здании, соединённом с башней стеклянным коридором.
- **Совместная работа.** Хаб — MCP-сервер `office` (`hub/office_mcp.py`): доска задач, переписка, найм, отчёт. На вкладке «Доска» этажа ставишь цель, и Диспетчер (Claude или Codex) режет её на задачи и нанимает до трёх исполнителей. Каждый работает в своём `git worktree` и своей ветке, сливает Диспетчер, а команды терминала и слияние одобряешь ты. Агенты будят друг друга не больше 40 раз за миссию, дальше ждут человека. Доска на стене этажа живая.
- **Приколы.** Агенты ходят между столом и диваном, у застрявшего дымится стол. Доска почёта с опытом и ачивками. Офисный кот. Погода Москвы (open-meteo) со снегом и дождём, ночью окна горят на тех этажах, где кто-то работает. Звуки (по умолчанию выключены). Планёрка в 9:00. Дрон доставляет твоё сообщение агенту.

- **Исполнители на других машинах.** `hub/runner.py` берёт задачи у хаба (на сервере это туннель к Маку), запускает агента на своей машине и возвращает его поток. Так офисные Клоды работают на Linux-сервере, где Claude залогинен. В окне найма выбираешь, где работать: на Маке или на сервере.

- **Отдельные чаты.** Кнопка «Чаты»: выбираешь модель (GPT на Маке, Claude на сервере, Gemini там, где он залогинен) и, при желании, проект, который модель может читать без права правок.
- **Смешанная команда.** Диспетчер нанимает Claude, GPT, Gemini и Grok-ботов. Grok-боты получают задачи через канал «входящие» (`<канал>-in`). Подключён и Cursor (`~/.cursor/hooks.json`).
- **Ревью веток.** Работу исполнителей коммитит офис. На вкладке «Доска» видны их ветки: разница по файлам, «Слить» и «Вернуть с замечанием». Слияние делает только человек.
- **Рецепты.** Готовые цели: почини тесты, ревью коммитов, найди баги, покрой тестами, обнови зависимости, README.
- **Расход и бюджет.** «История» считает токены за 14 дней по журналам Claude Code и Codex на всех машинах. Бюджет ставит миссии на паузу при высоком лимите. Есть «Стоп всем».
- **Ещё приколы.** Лифт для новых агентов, Grok-бот носит сообщения по мосту, свой вид у агента (имя, цвет, шапка), снег зимой, солнце над Москвой по реальному времени (ночь наступает сама), планёрка перед миссией и конфетти, когда она выполнена.

### Известные ограничения
- Claude на Маке из фонового хаба отвечает «Not logged in», потому что macOS не отдаёт ему ключ из связки ключей. Офисные Клоды работают через исполнителя на сервере.
- Antigravity на этом аккаунте отказывает: «not available in your location», через прокси VPN тоже.

## Установка на Мак

```sh
tar -cf - . | ssh mac 'mkdir -p ~/ai-office && tar -xf - -C ~/ai-office'
ssh mac '~/ai-office/deploy/mac/install.sh'               # launchd ru.ai-office.hub + сборка приложения
ssh mac 'python3 ~/ai-office/deploy/mac/hooks.py install'   # хуки Claude Code + Codex (с бэкапом)
ssh mac 'python3 ~/ai-office/deploy/mac/hooks.py uninstall' # откат хуков
```

Сессии Claude Code с Linux-сервера (туннель ssh до хаба на Маке + хук):

```sh
sh ~/ai-office/deploy/linux/install.sh
```

Логи хаба: `~/Library/Logs/ai-office-hub.log`. Перезапуск: `launchctl kickstart -k gui/$(id -u)/ru.ai-office.hub`.

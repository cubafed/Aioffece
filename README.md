# ИИ-Офис

Живой 3D-офис для всех ИИ-агентов на Маке: здание на острове, по этажу на проект, агенты за столами со статусами. Если агент ждёт разрешения, его можно одобрить прямо в офисе.

## Как устроено

```
Claude Code / Codex ──hook──▶ hub/office_hook.py ──HTTP──▶ hub/server.py (127.0.0.1:4747) ──SSE──▶ web/index.html
                                                                ▲                                   (в ИИ-Офис.app или браузере)
                                                                └──── POST /api/decide (кнопка «Одобрить»)
```

- `hub/server.py` — хаб, только стандартная библиотека Python 3.9 (системный `/usr/bin/python3` на Маке). Хранит состояние сессий, раздаёт интерфейс, шлёт обновления через SSE и сохраняет состояние в `data/state.json`.
- `hub/office_hook.py` — хук для Claude Code и Codex. Пересылает событие в хаб. При любой ошибке выходит молча (код 0, без вывода), поэтому агент работает как обычно. Решение о разрешении печатает, только если оно принято в офисе.
- `web/index.html` — интерфейс (three.js из `web/vendor`, при недоступности берётся с CDN). Если хаба нет (например, страница открыта как артефакт), включается демо-режим с выдуманными данными.
- `app/` — нативное окно `ИИ-Офис.app` (AppKit + WKWebView), собирается скриптом `app/build.sh`.

### Как статусы берутся из хуков
Этаж — имя git-корня из `cwd`.
- `UserPromptSubmit` → работает, задача = текст промпта.
- `PreToolUse` → работает, задача = описание инструмента.
- `PermissionRequest` → ждёт тебя.
- `Stop` → готово.
- `StopFailure` → застрял.
- `SessionEnd` → агент уходит из офиса.
- Если 15 минут нет событий → отдыхает; через 12 часов агент забывается.

### Разрешения
Vibe Island остаётся основным. Хук `PermissionRequest` ждёт решения из офиса, только пока офис открыт (есть SSE-зритель), и не дольше `approveWait` секунд (по умолчанию 60, меняется в окне «Подключить ИИ»). Если решения нет, хук выходит без вывода, и решать продолжают терминал или Vibe Island. Как Claude Code совмещает решения нескольких хуков PermissionRequest одновременно, пока не проверено вживую.

### Защита
Хаб слушает только `127.0.0.1`. POST-запросы проходят только с заголовком `X-Office: 1` и `Host` равным 127.0.0.1 или localhost, поэтому чужая страница в браузере не может одобрить действие.

## Установка на Мак

```sh
tar -cf - . | ssh mac 'mkdir -p ~/ai-office && tar -xf - -C ~/ai-office'
ssh mac '~/ai-office/deploy/mac/install.sh'               # launchd ru.ai-office.hub + сборка приложения
ssh mac 'python3 ~/ai-office/deploy/mac/hooks.py install'   # хуки Claude Code + Codex (с бэкапом)
ssh mac 'python3 ~/ai-office/deploy/mac/hooks.py uninstall' # откат хуков
```

Сессии Claude Code с Linux-сервера (туннель ssh до хаба на Маке + хук):

```sh
sh ~/ai-office/deploy/linux/install.sh
```

Логи хаба: `~/Library/Logs/ai-office-hub.log`. Перезапуск: `launchctl kickstart -k gui/$(id -u)/ru.ai-office.hub`.
